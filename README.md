Notes App 📝
A simple and clean notes application built with HTML, CSS, and JavaScript during early JavaScript learning.

Features
-Add a note title and detailed content
-Dynamically creates styled note cards on the page
-Lightweight and beginner-friendly codebase

How It Works
Enter a title and details in the input fields.
Click the Add button.
The new note is displayed in the list below.

Technologies Used
-HTML5
-CSS3
-JavaScript (DOM manipulation)
